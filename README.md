# 당뇨 & 건강 관리 앱 (Diabetes Tracker)

## 📱 개요

혈당, 약물, 검사 결과를 자동으로 분석하고 추적하는 당뇨 관리 PWA 앱입니다.

### ✨ 주요 기능

1. **일일 혈당 기록**
   - 아침/점심/저녁 식전, 식후 혈당 측정
   - 끼니별 메뉴 기록
   - 신체 증상 기록
   - 혈압, 맥박 기록
   - 운동 기록

2. **검사 결과 자동 분석**
   - 혈액검사 결과 텍스트 붙여넣기 → 자동 파싱
   - 인바디 결과 자동 분석
   - 약 처방전 자동 분류

3. **약물 관리**
   - 복용 약물 기록
   - 약 강도 변화 추적
   - 건강기능식품 기록

4. **통계 & 차트**
   - 혈당 추이
   - HbA1c 변화
   - 혈압 추이
   - 운동량 변화

5. **데이터 관리**
   - 로컬 저장 (프라이빗)
   - Google Drive 자동 백업 (설정 필요)
   - 마크다운 내보내기

## 🔧 기술 스택

- **React 18** - UI 라이브러리
- **Recharts** - 차트 그래프
- **Tailwind CSS** - 스타일링
- **PWA** - 오프라인 지원, 앱 경험

## 📦 설치 및 배포

### 1. GitHub 저장소 생성

```bash
# 깃 초기화
git init

# 모든 파일 추가
git add .

# 첫 커밋
git commit -m "초기 커밋"

# GitHub에 푸시 (remote 설정 후)
git push origin main
```

### 2. Vercel로 배포

1. [Vercel](https://vercel.com) 접속
2. "Sign Up" → "Continue with GitHub"
3. 이 저장소를 선택하여 Import
4. "Deploy" 클릭
5. 자동 배포 완료! (약 1분)

### 3. 앱 주소 확인

배포 완료 후:
```
https://diabetes-tracker-xxxxx.vercel.app
```

이 주소가 당신의 앱 URL입니다!

## 📱 핸드폰에 설치하기

### iOS (iPhone)
1. Safari에서 앱 URL 입력
2. 아래 공유 버튼 클릭
3. "홈 화면에 추가" 선택
4. 확인

### Android
1. Chrome에서 앱 URL 입력
2. 오른쪽 상단 점 3개 (⋮) 클릭
3. "앱 설치" 또는 "홈 화면에 추가"
4. 확인

## 🔐 데이터 보안

- ✅ 모든 데이터는 당신의 휴대폰에만 저장됨
- ✅ 서버에 저장되지 않음 (완전 프라이빗)
- ✅ Google Drive 백업은 선택사항
- ✅ 누구나 URL을 알 수 있지만, 각자의 데이터만 보임

## 🚀 오프라인 지원

PWA 기술로:
- ✅ 인터넷 없어도 마지막 데이터 볼 수 있음
- ✅ 기록 입력 가능 (온라인 복귀 시 동기화)
- ✅ 푸시 알림 가능

## 📝 사용 방법

### 혈액검사 결과 입력

1. "검사 결과" 탭 선택
2. "혈액검사" 영역에 다음 형식으로 붙여넣기:

```
검사일: 2025-01-15
HbA1c: 6.8
공복혈당: 125
총콜레스테롤: 210
HDL: 45
LDL: 150
중성지방: 180
GOT: 22
GPT: 28
크레아티닌: 0.9
```

3. "저장" 클릭

### 인바디 결과 입력

```
측정일: 2025-01-15
체중: 75.5
체지방률: 28.5
근육량: 52.3
기초대사량: 1650
BMI: 24.5
```

### 약 처방전 입력

```
처방일: 2025-01-15
- 메트포르민, 500mg × 2회
- 글리피지드, 5mg × 2회
- 리피토르, 10mg × 1회
```

## 🔄 Google Drive 백업 설정 (선택사항)

1. [Google Cloud Console](https://console.cloud.google.com) 접속
2. 새 프로젝트 생성
3. "Google Drive API" 활성화
4. OAuth 2.0 인증 정보 생성
5. API Key와 Client ID를 앱에 입력

## 📊 마크다운 내보내기

- 의사와 공유 가능
- 엑셀로 변환 가능

## 🐛 문제 해결

### Q: 데이터가 저장되지 않음
A: 브라우저의 로컬 스토리지를 확인하세요. 프라이빗 모드에서는 작동 안 함.

### Q: 오프라인에서 작동하지 않음
A: 처음 한 번은 온라인에서 앱을 열어야 서비스 워커가 설치됩니다.

### Q: 다른 기기에서 데이터 보고 싶음
A: Google Drive 백업을 설정하거나, 마크다운으로 내보내기.
